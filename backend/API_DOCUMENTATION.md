# Quantum Circuit Simulation Backend API

## Overview

The Quantum Circuit Simulation Backend is a Flask-based REST API that provides quantum circuit simulation capabilities, QASM generation, and integration with popular quantum computing frameworks like PennyLane and Qiskit.

**Version:** 1.0.0  
**Base URL:** `http://localhost:7900`  
**Content-Type:** `application/json` (unless specified otherwise)

## Endpoints

### Circuit Simulation

#### `POST /compute`

Simulate a quantum circuit and return state probabilities.

**Request:**
```http
POST /compute
Content-Type: text/plain

H-X-
X-H-
```

**Response:**
```http
HTTP/1.1 200 OK
Content-Type: text/plain

 1  |00⟩  ████████████████████  100% chance
```

**Description:**
- Takes circuit text in custom format
- Returns formatted probability output with ASCII bars
- Supports single-qubit gates: H, X, Y, Z, P, T, I
- Supports controlled gates: X#0, X#1 (CNOT)
- Supports SWAP gates: S#0, S#1

---

### QASM Generation

#### `POST /QASM`

Generate OpenQASM 2.0 code from circuit description.

**Request:**
```http
POST /QASM
Content-Type: text/plain

H-X-
X-H-
```

**Response:**
```http
HTTP/1.1 200 OK
Content-Type: text/plain

OPENQASM 2.0;
include "qelib1.inc";
qreg q[2];
creg c[2];
h q[0];
x q[1];
x q[0];
h q[1];
measure q[0] -> c[0];
measure q[1] -> c[1];
```

**Description:**
- Converts custom circuit format to OpenQASM 2.0
- Saves QASM code to `qasm_code.qasm` file
- Supports all standard quantum gates
- Includes measurement operations

---

### Unitary Parameters

#### `POST /unitary`

Set parameters for unitary gates (U, U1, U2).

**Request:**
```http
POST /unitary
Content-Type: application/json

{
  "key": "UNITARY",
  "theta": 1.5708,
  "phi": 0.0,
  "lambda": 0.0
}
```

**Parameters:**
- `key` (string): Gate type - "UNITARY", "UNITARY_1", or "UNITARY_2"
- `theta` (float): Rotation angle around Y-axis (radians)
- `phi` (float): Phase angle (radians)
- `lambda` (float): Additional phase angle (radians)

**Response:**
```http
HTTP/1.1 200 OK
```

**Description:**
- Sets global parameters for unitary gates
- Parameters persist for subsequent circuit operations
- Used in QASM generation for U/U1/U2 gates

### PennyLane Integration

#### `POST /simulate-pennylane`

Simulate circuit using PennyLane with QASM input.

**Request:**
```http
POST /simulate-pennylane
Content-Type: application/json

{}
```

**Response:**
```http
HTTP/1.1 200 OK
Content-Type: application/json

{
  "stdout": "\n 1  |00⟩  ████████████████████  100% chance\n",
  "returncode": 0
}
```

**Description:**
- Uses QASM file generated by `/QASM` endpoint
- Performs tensor network simulation
- Generates probability plot (saved as `figure.png`)
- Returns formatted state vector output

#### `POST /simulate-pennylane-qiskit`

Simulate circuit using PennyLane with Qiskit input.

**Request:**
```http
POST /simulate-pennylane-qiskit
Content-Type: application/json

{
  "qiskit_code": "from qiskit import QuantumCircuit\nqc = QuantumCircuit(2)\nqc.h(0)\nqc.cx(0, 1)"
}
```

**Response:**
```http
HTTP/1.1 200 OK
Content-Type: application/json

{
  "stdout": "\n 1  |00⟩  ████████████████████   50% chance    2  |11⟩  ████████████████████   50% chance\n",
  "returncode": 0
}
```

**Description:**
- Accepts Qiskit Python code directly
- Extracts circuit construction code
- Converts to PennyLane format
- Performs tensor network simulation

---

### Python Execution

#### `POST /execute-python`

Execute arbitrary Python code and return results.

**Request:**
```http
POST /execute-python
Content-Type: application/json

{
  "code": "import numpy as np\nprint('Hello, Quantum!')"
}
```

**Response:**
```http
HTTP/1.1 200 OK
Content-Type: application/json

{
  "stdout": "Hello, Quantum!\n",
  "stderr": "",
  "returncode": 0
}
```

**Description:**
- Executes Python code in isolated environment
- 50-second timeout limit
- Automatically adds plotting code for quantum frameworks
- Fixes complex number notation (j → 1j)

**Supported Frameworks:**
- Qiskit
- Cirq
- Amazon Braket
- PennyLane

## Error Handling

The API uses standard HTTP status codes:

- `200 OK` - Request successful
- `400 Bad Request` - Invalid request parameters
- `404 Not Found` - Endpoint not found
- `408 Request Timeout` - Execution timeout
- `500 Internal Server Error` - Server error

**Error Response Format:**
```json
{
  "error": "Error message description"
}
```

## Circuit Format

The custom circuit format uses a grid-based representation:

```
Gate1-Gate2-Gate3
Gate4-Gate5-Gate6
```

**Supported Gates:**

| Gate | Description | Example |
|------|-------------|---------|
| `H` | Hadamard | `H` |
| `X` | Pauli-X | `X` |
| `Y` | Pauli-Y | `Y` |
| `Z` | Pauli-Z | `Z` |
| `P` | Phase | `P` |
| `T` | T-gate | `T` |
| `I` | Identity | `I` |
| `X#0` | CNOT control | `X#0` |
| `X#1` | CNOT target | `X#1` |
| `S#0` | SWAP qubit 1 | `S#0` |
| `S#1` | SWAP qubit 2 | `S#1` |
| `U` | Unitary | `U` |
| `U1` | Unitary 1 | `U1` |
| `U2` | Unitary 2 | `U2` |

**Multi-qubit Gates:**
- `X.0#0`, `X.0#1` - Multi-CNOT with group 0
- `S.0#0`, `S.0#1` - Multi-SWAP with group 0

## Response Formats

### Probability Output

```
 1  |00⟩  ████████████████████  100% chance
 2  |01⟩  ░░░░░░░░░░░░░░░░░░░░    0% chance
```

- Numbered entries
- Bitstring representation
- ASCII bar chart (20 characters)
- Percentage probability

### State Vector Output (PennyLane)

```
 1  |00⟩  ████████████████████   50% chance    2  |11⟩  ████████████████████   50% chance
```

- Side-by-side display
- Reversed bit order (LSB first)
- Same bar chart format

## Examples

### Basic Circuit Simulation

```bash
curl -X POST http://localhost:7900/compute \
  -H "Content-Type: text/plain" \
  -d "H-X-
X-H-"
```

### Generate QASM

```bash
curl -X POST http://localhost:7900/QASM \
  -H "Content-Type: text/plain" \
  -d "H-X-
X-H-"
```

### Set Unitary Parameters

```bash
curl -X POST http://localhost:7900/unitary \
  -H "Content-Type: application/json" \
  -d '{"key": "UNITARY", "theta": 1.5708, "phi": 0.0, "lambda": 0.0}'
```

### Execute Python Code

```bash
curl -X POST http://localhost:7900/execute-python \
  -H "Content-Type: application/json" \
  -d '{"code": "from qiskit import QuantumCircuit\nqc = QuantumCircuit(2)\nqc.h(0)\nqc.cx(0, 1)\nprint(qc)"}'
```
